# Лабораторна робота №20 — Список справ із Firebase

Виконала: Безкровна Анастасія Дмитрівна, група Інб-1-24-4-0д.

Це продовження лабораторної роботи №18. Інтерфейс і основні функції списку справ збережено, а локальне збереження замінено на Firebase Realtime Database через REST API.



## Використані методи
- `POST /todos.json` — створити справу, отримати Firebase-ключ `name`.
- `GET /todos.json` — прочитати всі справи; об'єкт перетворюється на масив.
- `PATCH /todos/<key>.json` — змінити поле `completed`.
- `DELETE /todos/<key>.json` — видалити одну справу.
